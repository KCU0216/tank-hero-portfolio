# Tank Hero

**김찬울 · Unreal Engine 5 · C++ · 개인 프로젝트**

공격 예고와 파츠 공략을 중심으로 구성한 탱크 탄막 보스전입니다. 이 저장소에는 핵심 설계 설명과 구현 확인용 CPP 코드 발췌를 수록했습니다.

## 주요 구현

- 캐논 궤적·박격포 착탄 데칼·레이저 충전 방향을 통한 공격 예고
- 탱크·미니포탑·보스에서 사용하는 레이저 컴포넌트와 미니포탑·보스의 박격포 컴포넌트
- 포물선 방정식의 고각·저각 해를 이용한 발사각 계산
- 레이저의 액터별 중복 피격 제거와 카메라·포신 조준점 분리
- 4페이즈 보스, 파츠 파괴와 코어 직격 2배 피해

## 수록 범위

전체 빌드용 Unreal 프로젝트가 아닌 CPP 중심의 포트폴리오 발췌본입니다. 헤더, 프로젝트 설정, 전체 Blueprint 및 외부 유료 에셋은 포함하지 않았습니다.

탄도 계산의 실패 반환값을 박격포 호출부에서 검사하지 않는 점 등 현재 구현의 제약은 [핵심 코드 설명](Source_Code/CODE_HIGHLIGHTS.md)의 마지막 항목에서 확인할 수 있습니다. 캐논 전체가 공통 무기 컴포넌트를 공유하는 구조로 설명하지 않습니다.
